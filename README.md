# CS PhD Statement of Purpose (SoP) LaTeX Template

A simple LaTeX template with an example Statement of Purpose (SoP) for CS PhD and graduate school applicants.

I made this repository public in the spirit of paying it forward. When I was applying to PhD programs, seeing concrete examples helped me understand what a strong SoP could look like. I hope this helps future applicants do the same.

Best of luck, you got this! :)

## What's Included

- `SoP.tex`: Editable LaTeX source for the statement of purpose.
- `SoP.pdf`: Compiled example PDF.
- `LICENSE.md`: CC0 license, so you can freely reuse and adapt the template.

## Who This Is For

This template is useful for students applying to:

- Computer Science PhD programs
- Systems, ML, AI, and other research-focused graduate programs
- Research-based MS or PhD programs
- Graduate school programs that require a Statement of Purpose

The template is intentionally simple. The goal is to give you a clean starting point, not to constrain your writing.

## How to Use

Clone the repository:

```bash
git clone https://github.com/Swapnil-Gandhi/SoP-Template.git
cd SoP-Template
```

Edit `SoP.tex`, then compile:

```bash
pdflatex SoP.tex
```

This should produce `SoP.pdf`.

## Using Overleaf

You can also use this template in Overleaf:

1. Download this repository as a ZIP file.
2. Open Overleaf.
3. Create a new project from the ZIP file.
4. Edit `SoP.tex`.
5. Compile the project.

## Notes for Applicants

A strong Statement of Purpose is not just a list of accomplishments. It should explain what research problems excite you, what experiences prepared you to work on those problems, why graduate school is the right next step, and why the specific program is a good fit.

Please use this as a structural reference, not as text to copy. Your statement should sound like you.
